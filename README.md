
# 🐾 OmniPaw

**OmniPaw** is a web application that simplifies shared pet care by keeping tracking tools, health schedules, and documents in one unified location.

## ✨ Features

- **Centralized tracking** – keep every pet's routines, activities, and care history in one place
- **Health schedules** – manage vaccinations, vet appointments, medications, and reminders
- **Document storage** – store important records (vet records, licenses, insurance) securely
- **Seamless care handoffs** – share up-to-date care information so nothing gets lost between caregivers

## 👥 Who It's For

OmniPaw is built primarily for:

- Pet owners
- Families sharing pet responsibilities
- Pet sitters
- Boarding facilities

With OmniPaw, care responsibilities can be handed off smoothly — without losing track of important routines.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/omnipaw.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
